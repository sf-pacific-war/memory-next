# 中国大陆档案来源：精选资料、访问检查与接入范围

本应用接入两家有明确档案出处、且与中国及缅甸战场直接相关的中国大陆机构：**中国第二历史档案馆（Second Historical Archives of China，SHAC）**和**云南省档案馆（Yunnan Provincial Archives）**。当前收录 4 条经过人工选择的档案展示或馆藏指南记录；全站目录共 59 条记录、12 个来源机构。

这些入口提供可阅读的官方档案展示或馆藏说明。当前接入方式是**精选记录与原站链接**，没有接通这两家机构的全馆目录或实时检索 API。网页上的搜索仍然查询本站已收录的目录；命令行在线检查用于核验选定链接，不能据此声称已检索全馆。

## 命令行检查

在本应用目录执行；开发工作目录为 `step1-discovery/`，`memory-next` 仓库中为 `step1/`。

```sh
# 离线列出当前选定记录；不访问外站，也不需要凭据
python3 tools/check_mainland_sources.py

# 在线检查两家机构已收录记录的官方链接
python3 tools/check_mainland_sources.py --live --source all

# 只检查一家机构；输出表格便于人工阅读
python3 tools/check_mainland_sources.py --live --source shac --format table
python3 tools/check_mainland_sources.py --live --source yunnan --format table

# 先在本地选定记录中匹配关键词，再检查命中记录的原站链接
python3 tools/check_mainland_sources.py --live --source all --query '密支那'
python3 tools/check_mainland_sources.py --live --source yunnan --query '南侨'
```

`--source` 接受 `all`、`shac`、`yunnan`。`--query` 过滤的是已收录记录的本地标题，并没有将关键词发送到对方全馆搜索系统。零命中表示当前精选记录没有匹配项，不表示该机构没有相关档案。在线检查不自动新增记录、下载整批影像或改写网站目录。HTTP 成功只能证明被检查的链接在检查时可读取，不能证明完整馆藏开放或具备实时 API。

当前 4 条记录已通过工具的真实在线检查：4 次请求均获得正常 HTTP 响应，并匹配预期 HTML 内容标记。项目完整测试通过 240 项 Python 测试和 25 项 JavaScript 测试。

修改选定记录或检索字段后，应运行项目测试并重新构建公开数据，再部署：

```sh
python3 -B -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.mjs
python3 tools/build_site_data.py
python3 tools/serve.py
```

## 权利与数据语义

目前未确认这些条目的开放许可。公开可访问、可显示原站预览、可下载完整扫描和可重新出版是不同层面的判断，不将其标记为公有领域或 Creative Commons。原站图片保留原站地址及提供机构；需要转载、高分辨率下载、OCR 全文或模型训练材料时，应另行核实适用条件。

每条记录区分档案提供机构、网页发布机构、原件日期或内容覆盖日期、网页发布日期以及本站核查时间。本站编写的中英文介绍属于编辑说明，不作为馆方原始摘要。未见原始档号、文件制作日期或逐件权利时保持未知，不据网页编号、路径或主题推断。

## 生产接入下一步

1. **维持可核查的精选目录。** 对官方链接设置低频、有限请求的健康检查，记录最后成功状态；原站失效时保留来源说明，停止声称可以在线阅读。
2. **扩展真实相关材料。** 继续围绕远征军、驻印军、滇缅公路和航空运输选择有原件、扫描、转录或具体馆藏说明的页面，避免用机构新闻和展览开幕通知增加来源数量。
3. **取得正式机器接入条件。** 若机构提供官方 API、数据导出或合作服务，先确认字段、分页、身份认证、限流、缓存及再利用规则，再新增独立适配器；目前没有已验证可用的全馆 API 凭据注册流程。
4. **核对档案层级与稳定链接。** 优先保存可核实的全宗、案卷、单件编号；区分展览选件与完整案卷，同一物件跨馆出现时保留各自出处，不能只按相似标题合并。
5. **逐件核实影像范围与权限。** 完整影像、正文转录及可供 LLM 引用的文本需另外建立页级来源、处理版本和可使用范围，目录标题不能作为全文证据。
