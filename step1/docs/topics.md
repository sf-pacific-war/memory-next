# 专题浏览与资料发现

网站三个入口依次为 **资料发现 / Discover**、**专题浏览 / Topics**、**数据来源 / Sources**。资料发现用于主动检索；专题浏览用于从已有主题阅读资料。两者读取同一份公开目录，目前有 55 条去重记录、10 个来源机构、10 个双语专题。

## 本地预览

在应用目录运行：

```sh
python3 tools/serve.py
```

- 中文检索：`http://127.0.0.1:8000/?lang=zh-CN&q=飞虎队`
- 英文浏览：`http://127.0.0.1:8000/topics.html?lang=en&browse=flying-tigers`
- 驼峰专题：`http://127.0.0.1:8000/topics.html?lang=zh-CN&browse=hump-airlift`

## 演示顺序

1. 在资料发现搜索“飞虎队”，查看跨来源结果和扩展词；用来源、类型筛选，打开一条资料详情。
2. 切换至第二个导航“专题浏览”。浏览照片、文献与实物，选择驼峰航线或战时报刊与生活指南。
3. 点击专题关键词，跳回资料发现开始关键词搜索；点击“在资料发现中检索这个专题”，查看该专题的完整记录集合，并继续筛选。
4. 切换 English／中文，检查专题导读随界面切换、原始档案标题保持原文。
5. 在数据来源查看机构数量和收录方式；区分 API、公开数据集与人工整理入口。

专题的 `browse` 参数只控制浏览页。导航返回可保留先前搜索条件；专题关键词和专题检索链接会开始一组明确的新检索。旧 `/cbi-demo.html` 地址兼容跳转，不再展示参考对照、清单或访问日志。

## 数据维护

- `data/topics.json`：双语专题标题、说明、关键词、成员与编辑导读。
- 来源快照与 `data/cbi/archive-records.json`：外馆元数据候选；台湾档案管理局（Taiwan NAA）快照为 `data/taiwan-discovery.json`。
- `data/cbi/verified-matches.json`：内部核查依据；只有允许的原馆记录字段进入统一目录。
- `data/review-notes.json`：明确排除的记录。
- `python3 tools/build_site_data.py`：离线生成 `site/data/catalog.json`；`serve.py` 与 Firebase 发布钩子均调用此构建器。

编辑导读与专题关键词不冒充原馆描述。参考站地址、对照判断、爬取清单、日志和内部备注不进入公开目录。预览仅来自允许的档案机构域名；日期缺少结构化依据时仍标记不详。完整原馆权利和出处可在资料发现的详情中查看。台湾案卷保留全宗、档号和 A+ 检索入口；已核查的驻印军专题另以原馆阅读链接提供。CSV 的资料产制日期不填入历史日期，目录记录不等于全文／影像开放，详情和预览必须保持此区别。
